    serveAdmission

    • serveAdmission(
          hooks: AdmissionHooks,
          options?: { upcalls?: Upcalls },
      ): { upcalls: Upcalls; close(): void }

      Answer this node's admission requests with hooks over upcalls (kinds admission_handshake / admission_connect) — the alternative to admission; one or the other per node. An attached gate still decides first. Without an answer (error, timeout) the upcall policy's failure mode decides (fail-closed by default: a handshake is rejected with 403 "hook unavailable"); keep its timeout below the node's hookTimeoutMs. Outbound dials are allowed unless hooks.connect says otherwise. close() on the result removes the hooks (later requests then get the failure mode).

      Parameters

      • hooks: AdmissionHooks
      • Optionaloptions: { upcalls?: Upcalls }

      Returns { upcalls: Upcalls; close(): void }
