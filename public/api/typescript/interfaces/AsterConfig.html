    Interface AsterConfig

    Aster configuration. Every field is optional; omitted fields take the Rust defaults. The loaders return every field filled in (keys as hex strings).

    The u64 knobs accept number or bigint; loaders return a number unless the value exceeds Number.MAX_SAFE_INTEGER.

    OptionalrootPubkey

    rootPubkey?: KeyMaterial

    Deployment root public key. ASTER_ROOT_PUBKEY, [trust] root_pubkey.

    OptionalrootPubkeyFile

    rootPubkeyFile?: string

    File with the root public key (hex or {"public_key": "<hex>"}).

    OptionalenrollmentCredentialFile

    Enrollment credential file. ASTER_ENROLLMENT_CREDENTIAL.

    OptionalenrollmentCredentialIid

    OptionalallowAllConsumers

    allowAllConsumers?: boolean

    Skip the consumer admission gate (dev mode). ASTER_ALLOW_ALL_CONSUMERS.

    OptionalallowAllProducers

    allowAllProducers?: boolean

    Kept for schema parity with Rust. Producer mesh admission is not supported by the TypeScript binding: AsterServer throws on false.

    OptionalendpointAddr

    endpointAddr?: string

    Producer address for consumer-side dialing. ASTER_ENDPOINT_ADDR.

    OptionalstoragePath

    storagePath?: string

    Persistent node directory; in-memory when unset. ASTER_STORAGE_PATH.

    OptionalgcIntervalMs

    gcIntervalMs?: number | bigint

    Blob GC interval (ms); 0 / unset = no GC. ASTER_GC_INTERVAL_MS.

    OptionalsecretKey

    secretKey?: KeyMaterial

    Node secret key. ASTER_SECRET_KEY, [network] secret_key.

    OptionalsecretKeyFile

    secretKeyFile?: string

    Node secret key file (64 hex characters) — the one on-disk identity format shared with Rust and every binding. Loaded at start if it exists (an explicit secretKey that disagrees is an error), otherwise created (mode 0600) from secretKey or a fresh key. ASTER_SECRET_KEY_FILE.

    OptionalidentityFile

    identityFile?: string

    .aster-identity credential file. ASTER_IDENTITY_FILE, [identity] file.

    OptionalbindAddr

    bindAddr?: string

    Local bind address, e.g. "0.0.0.0:9000". ASTER_BIND_ADDR.
