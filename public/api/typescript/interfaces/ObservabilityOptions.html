    Interface ObservabilityOptions

    Options for observabilityInit. Explicit fields beat OTEL_* / ASTER_* env (read unless fromEnv is false), which beats extraToml, which beats the defaults.

        exportTraces?: boolean;
        exportMetrics?: boolean;
        exportOtlpLogs?: boolean;
