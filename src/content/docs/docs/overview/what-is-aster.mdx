Aster is a peer-to-peer application SDK with typed RPC services. Applications connect to an endpoint's cryptographic identity and configure admission and method permissions to control access. It is intended for services that run across developer machines, customer networks, and cloud instances.

Aster is a public preview. It provides Rust, Python, TypeScript, Go, Java, and .NET APIs against the same Rust engine. The preview does not provide a general-availability stability guarantee.

## A remote-worker application

Suppose workers run in customer networks and an operator dispatches jobs from
cloud infrastructure. A worker's endpoint key identifies it when its IP address
changes. Typed RPC carries job requests and status responses. Large job inputs
can move as blobs, while documents replicate references and observations.

Those parts have different responsibilities. A discovered worker may be
unreachable by the time a call starts. A replicated status entry can arrive
late. If only one worker may publish a result, the application needs an
agreed ownership decision and a resource that rejects stale fences. Admission
and method policy determine which workers and operators may participate.

Start with RPC and add data or coordination when the application requires
them; a first service does not need every subsystem.

## Endpoint identity and connectivity

Each endpoint has an Ed25519 keypair. Its public key, the `EndpointId`, identifies the peer independently of its IP address. The [Iroh](https://iroh.computer/) transport uses address hints and configured discovery mechanisms to find a path, authenticates both endpoints, and encrypts the connection.

Iroh attempts direct connectivity and can use a relay when a direct path is unavailable. Reachability still depends on network policy, available address information, and relay access. See [transport](/docs/concepts/transport/).

## Typed services and serialization

Define services in application code using the language's decorators, annotations, attributes, or Rust APIs. Aster derives a canonical contract and hashes it with [BLAKE3](https://github.com/BLAKE3-team/BLAKE3) to produce a `contract_id`. Implementations must agree on method names, wire types, and contract settings to compute the same identity.

[Apache Fory](https://fory.apache.org/) provides the default cross-language serialization format. Dynamic tools convert JSON input to typed XLANG payloads using a contract schema. Transport encryption applies to RPC traffic. See [serialization](/docs/concepts/serialization/) and [contract identity](/docs/concepts/contract-identity/).

## Access control and discovery

Configured enrollment workflows can establish deployment membership. Method capability requirements restrict calls after admission. These protections depend on the configured trust policy; the quickstart's development settings allow unauthenticated application access. Read the [trust model](/docs/concepts/trust-model/) before deploying with sensitive data.

The [service registry](/docs/concepts/discovery/) uses Iroh documents, blobs, and gossip to replicate contract and endpoint information between participating peers. Applications can also connect using an explicit endpoint address.

## Data and coordination

RPC is one part of the SDK. [Blobs and documents](/docs/guides/data/) store
content and replicate signed entries. [Topology](/docs/guides/topology/)
helps select peers from measured locality and path quality.
[Sealed grants](/docs/guides/sealed-grants/) distribute capabilities to named
recipients. [Coordination](/docs/guides/coordination/) serializes critical state,
with [fenced leases](/docs/guides/leases/) for protected single-writer resources.

Rust services can also use [HTTPS and WebTransport](/docs/guides/http/).
[HTTP exposure](/docs/guides/expose/) connects an existing HTTP application
through an Aster peer or public edge.

## Language support

Rust is the native facade. Python, TypeScript, Go, Java, and .NET adapt the
shared Rust engine to their runtimes. Package delivery, enrollment workflows,
and newer feature helpers differ. Kotlin uses the JVM runtime and is not
independently qualified in the six-language RPC matrix.

Use the [language and release matrix](/docs/reference/compatibility/) to choose
a binding. Start with the [Rust quickstart](/docs/quickstart/rust/) or
[Python and TypeScript quickstart](/docs/quickstart/python/).
