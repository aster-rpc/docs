Aster is a peer-to-peer application SDK. Define a typed service,
connect to a peer by its cryptographic identity, and control which calls it may
make. Use the SDK to connect services across developer machines, customer
networks, and cloud instances.

Aster 0.3.893 is a public preview. It provides Rust, Python, TypeScript, Go, Java, and .NET APIs against the shared Rust engine. See [what is Aster?](/docs/overview/what-is-aster/) for language status and [why Aster?](/docs/overview/why-aster/) for the deployment requirements it addresses.

## Try the preview

Create a service and call it from a second process. The quickstart includes
Python and TypeScript examples. These guides have not yet been validated word for word on a clean host for
0.3.893. Package versions on PyPI and npm may differ from the Forgejo preview.

## Understand the connection

Peer identity, network connectivity, and permission are separate parts of an
application. Learn how they fit together before configuring a trusted deployment.

- [Peer connections](/docs/concepts/transport/) — identities, direct paths, and relay fallback.
- [Trust model](/docs/concepts/trust-model/) — admission, credentials, and method permissions.
- [Contract identity](/docs/concepts/contract-identity/) — how service interfaces are identified.

## Find the API and settings

- [Python guide](/docs/bindings/python/) — installation and the language surface.
- [Configuration](/docs/reference/configuration/) — settings, defaults, and environment variables.
- [Python API](/api/python/aster/public.html) and [TypeScript API](/api/typescript/) — generated reference.

The SDK is built on [Iroh](https://iroh.computer/) for peer connectivity and
[Apache Fory](https://fory.apache.org/) for serialization. The
[Aster website](https://aster.site/) introduces the project and its examples.
